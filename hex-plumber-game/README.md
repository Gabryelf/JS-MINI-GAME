# Hex-Plumber-Game

## Казуальная многоуровневая веб игра с реализацией собственной механики - устранение утечки. Попробуйте запустить прямо в браузере по ссылке внутри репозитория.

## Особенности реализации

### Архитектура
> CommonJS-стиль: Все модули используют самовызывающиеся функции и глобальное пространство имен
> Модульность: Четкое разделение на core, ui, sdk и utils
> Событийная модель: Слабая связанность через колбэки

### Геймплей
> Гексагональное поле с системой совместимости
> 3 карты в руке, пополняются автоматически
> Поворот карт доступен при течи ≤ 3
> Инструменты (ключи) для замены карт
> Система прогресса и затопленности

### Интеграция с Яндекс SDK
> Автоматическое определение окружения
> Заглушка для браузера (localStorage)
> Полная поддержка API (данные игрока, реклама)

### UI/UX
> Адаптивный дизайн под мобильные устройства
> Кастомные иконки через SVG (без внешних зависимостей)
> Плавные анимации и визуальная обратная связь
> Модальные окна для настроек и сообщений
